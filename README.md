# Todo App Backend API - Tugas #4

Backend RESTful API untuk aplikasi Todo List menggunakan Express.js, TypeScript, dan MySQL. Proyek ini dilengkapi dengan autentikasi JWT dan validasi input.

## Persyaratan Sistem
- Node.js (v18 atau lebih baru)
- MySQL Server (XAMPP/Laragon)

## Cara Setup Proyek
1. *Clone* repositori ini ke komputer lokal.
2. Buka terminal di dalam folder proyek dan jalankan perintah:
   ```bash
   npm install
